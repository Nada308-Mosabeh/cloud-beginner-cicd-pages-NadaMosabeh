What is CI/CD?

CI/CD stands for Continuous Integration and Continuous Deployment. It is a way to automate the process of testing and deploying code. When a developer pushes changes to the repository, GitHub Actions can run a workflow automatically. This makes development faster, reduces manual work, and helps deliver updates in a reliable way.

My Pipeline

After I push my code to the main branch, GitHub Actions starts the workflow. It checks that the required files exist, then uploads the website files and deploys them to GitHub Pages. After that, the updated website becomes live online.
